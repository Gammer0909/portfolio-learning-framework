Outstanding Coursework

Account System (Go)

A functional frontend template website with a backend written in golang and mux for my Computer Programming I class. The frontend was built with HTML, CSS, and JavaScript, with the backend and APIs being written purely in go, with a CSV database. This project was given to me to learn the fundamentals of web design and function, but most importantly the inner workings of a backend and API.

While the original project scope was to just implement the backend and API, I also implemented basic password hashing and security using bcrypt.

Superheroes and King Arthur

Superheroes and King Arthur is a paper I wrote analyzing the differences and many similarities between modern superhero stories and those of Arthurian legend.

This paper was a written analysis for my World Literature I class. Prior to this essay, we watched various superhero films in class and analyzed them together.

Math Fair - MiniMax

An implementation of the MiniMax search algorithm for tic-tac-toe, built for my school's math fair. The project has an implentation of the MiniMax algorithm in C#, complete with a small terminal-based UI using a custom ANSI-based console rendering system. This project also has a basic python application that links to the chess engine Stockfish, to establish what MiniMax as a search algorithm can do in a more complex game.

My group presented this project by allowing math fair goers to challenge the tic-tac-toe algorithm, of whome it bested around 50%. This project was able to secure 5th place at our math fair, along with a small monetary prize.
